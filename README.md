# تحدّي الصفّ الآمن

تطبيق ويب تفاعلي باللغة العربية لإدارة مسابقة الفرق الستة داخل الصف، مع لوحة نقاط، جولات وأسئلة، مؤقت، ألعاب تفاعلية، ونتائج نهائية.

## التشغيل

افتح ملف `تحدي_الصف_الآمن.html` مباشرة في متصفح حديث. لا يحتاج المشروع إلى خادم أو تثبيت حزم.

## ملاحظات

يستخدم التطبيق خطوط Google Fonts عند توفر اتصال بالإنترنت، ويعمل كذلك دونها باستخدام الخطوط الاحتياطية المضمّنة في CSS.

## الترخيص

هذا المستودع يحتوي على المشروع المرفق كما تم تسليمه.
